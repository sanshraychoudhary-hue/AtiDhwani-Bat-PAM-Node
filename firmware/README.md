# AtiDhwani Bat PAM Node Firmware

This directory contains the complete real-time acoustic signal processing firmware for the **AtiDhwani Bat Passive Acoustic Monitoring (PAM) Node**, running on an **ESP32-S3 (Dual-Core Xtensa LX7 @ 240 MHz with 8MB Octal PSRAM)**.

---

## 1. Key Firmware Features

* **Dual-Core Architecture:**
  * **Core 0 (Audio Engine & I/O):** High-speed I2S DMA streaming from WM8782 ADC (192 kHz 24-bit stereo) and out to PCM5102A DAC (48 kHz 32-bit), real-time ring buffering in 8MB PSRAM, and non-blocking FAT32 WAV file streaming.
  * **Core 1 (DSP & UI):** Real-time heterodyne mixing, time expansion synthesis, frequency division, 128-point Radix-4 FFT spectral calculation, 0.91" OLED UI updates (30 FPS), button debouncing, and rotary encoder state machines.
* **Acoustic Transformation Modes:**
  1. **Heterodyne (HET):** Direct quadrature down-conversion with a tunable local oscillator ($15\text{ kHz} - 90\text{ kHz}$) selectable via the EC11 rotary encoder.
  2. **Frequency Division (DIV):** Zero-crossing detection engine scaling down ultrasonic frequencies ($1/10$ or $1/16$ divisor).
  3. **Time Expansion (TE):** Captures high-frequency acoustic bursts and plays them back slowed down by $10\times$ preserving full wave harmonics.
  4. **Direct Pass-Through / Monitor:** Auditory diagnostic monitoring of raw channels.
* **Auto-Trigger & Continuous WAV Recording:**
  * Amplitude threshold triggering with a 5-second pre-trigger circular ring buffer stored in PSRAM (ensures bat call attack transients are never lost).
  * Standard RIFF WAV format: 192 kHz, 16-bit stereo, timestamped filenames (`BAT_YYYYMMDD_HHMMSS.WAV`).
* **On-Board Diagnostics & Telemetry:**
  * Battery state-of-charge estimator via GPIO2 ADC (1:2 precision voltage divider).
  * Storage capacity monitor (free space, file counts, write speed).
* **Web Companion Portal (Optional AP/STA):**
  * Embedded HTTP web server and WebSocket interface for wireless parameter configuration, live acoustic waterfall spectrogram streaming, and WAV file download over WiFi.

## 3. Build & Flashing Setup

### Prerequisites

* **Arduino IDE 2.x** or **PlatformIO** (VS Code)
* **ESP32 Arduino Core:** Version `2.0.14` or later (tested up to `3.x`)
* **Required Libraries:**
  * `Adafruit_SSD1306` & `Adafruit_GFX` (for OLED display)
  * `FS` & `SD` (built-in ESP32 SD library)
  * `WiFi` & `WebServer` (built-in ESP32 core)

### Arduino IDE Board Configuration

Select **ESP32S3 Dev Module** under **Tools > Board > esp32**:

| Parameter | Setting | Reason |
| :--- | :--- | :--- |
| **Board** | `ESP32S3 Dev Module` | Target microcontroller |
| **USB CDC On Boot** | `Enabled` | Enables Serial print over native Type-C port |
| **Flash Size** | `16MB (128Mb)` | Matches N16R8 module flash |
| **Partition Scheme** | `16M Flash (3MB APP / 9.9MB FATFS)` | Maximizes application and local log space |
| **PSRAM** | `OPI PSRAM` | **CRITICAL:** Enables 8MB high-speed Octal PSRAM |
| **CPU Frequency** | `240MHz (WiFi)` | Maximum compute performance for DSP |
| **Flash Mode** | `QIO 80MHz` | Fast SPI flash access |
| **Upload Speed** | `921600` | Fast flashing |
